Why AgentHelm

Fleets don't break down in the coding. They break down in the human's attention: a permission prompt in a terminal you weren't watching, a stalled agent discovered an hour late, a handoff that lost the thread. AgentHelm is built for that side of the fleet.

One board, whole fleet

Every agent session across every project: working, waiting, idle, done, stalled — with current task and last activity. Stall detection is automatic, not something you notice by luck.

Approvals inbox

Every permission prompt, question, and decision request from every tool, in one queue. Clear twenty decisions in a batch instead of babysitting four terminals.

Burn accounting

Token and cost burn per agent, rolled up per project — computed from your agents' own session logs, with estimates labeled as estimates. Know what today's fleet cost before the invoice does.

Handoff briefs, automatic

When an agent finishes or gets replaced, AgentHelm writes the brief — task, decisions, files touched, open items — and hands it to the successor. Context stops being hand-carried, permanently.

Cross-tool, Cursor included

Claude Code, Codex CLI, GitHub Copilot, OpenCode — and the Cursor-class agents BAND launched without. Adapters read each tool's own session store; a generic adapter tracks any long-running agent process.

Local-first and instant

The console runs on your machine and reads local session data. No account to start, nothing leaves the box, interactions stay under 100ms, and the whole board is keyboard-driven.

Flat plans from $0

Free for up to 3 agents. Pro is $19/mo with the approvals inbox and burn accounting. Fleet is $49/mo with task routing. Published prices, no sales call — the way fleet tools should be sold.
