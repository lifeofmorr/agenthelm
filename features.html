Features

Everything BAND has. Plus the helm.

BAND (Thenovi AI, Oct 2026) gave fleets a shared room. AgentHelm matches the coordination layer — and adds the operator's instruments BAND left out. Anything marked staged on this page is on the roadmap, not in the box today.

Approvals inbox

Attention is the bottleneck. This is the fix.

Agents don't wait politely in one place. Their questions scatter across terminals, tools, and machines. The approvals inbox is the single queue where all of it lands — sorted, batch-clearable, logged.

  • Every kind of ask — permissions, questions, decision requests
  • Context attached — which agent, which project, how long it's waited
  • Keyboard-first — j/k select, a approve, d deny, r refresh
Approvals inbox — 2 waiting on you

The inbox, live from the demo board. The selected item is outlined — one keystroke clears it.

Burn accounting

Fleets burn money visibly, or invisibly.

Every agent card carries its token burn and estimated cost, rolled up to a fleet total in the board header. Five agents for a day is a real line item — AgentHelm shows it today, not at month-end.

  • Per agent, per project, per fleet — three levels of rollup
  • Read from session logs — the usage your agents already record
  • Status at a glance — working, waiting, idle, done, stalled, on every card
Fleet — burn by agent

The demo fleet: 812,400 tokens on the refactor, 402,150 on tests — every card priced, every status visible.

Handoff briefs

Continuity is a document, not a memory.

Sessions end; work shouldn't restart. One click — or the b key — generates the brief for any session: task, decisions and approvals, files touched, open items, and a start-here prompt written for the successor.

  • Generated from the session itself — not hand-written, not forgotten
  • Successor-ready — includes the exact prompt to resume the task
  • Burn included — the next agent knows what the work has cost so far
Handoff brief — billing-service

A real brief, generated from the demo board's own session data.

Cross-tool by design. Local by default.

Adapters read each tool's own session store — no plugins to install inside your agents, no wrapper commands to learn. A generic adapter tracks any long-running agent process, which is how Cursor-class agents are covered today. And the console runs on your machine: your code and prompts stay on your box.
